The repository is well-structured and covers all major requirements
of both assignment parts. Notebook 1 (linear regression) implements
dataset visualization, the cost surface, analytical gradients, both
loop-based and vectorized gradient descent, three learning-rate

demonstration. The README provides SageMaker execution evidence with

mandatory elements are present; only minor shortcomings are noted
(see Issues section below).

TA FEEDBACK TO STUDENT
────────────────────────────────────────────────────────────────────
Excellent work overall. The repository satisfies every mandatory
requirement and the implementation is technically correct. To
improve, focus on three areas:

1. Deepen your written analysis. When you show a convergence plot
   comparing three learning rates, explain what you observe
   quantitatively: does lr=0.05 overshoot? By how much does the
   final loss differ across rates? These observations demonstrate
   understanding beyond code execution.

2. Make both gradient implementations observable. Add a short
   cell that runs gradient_descent with vectorized=False for one
   or two iterations and prints the resulting (dw, db) alongside
   the vectorized version to confirm they match. This validates
   your implementation and makes the notebook self-contained.

3. Complement the 3D cost surface with a 2D contour plot and,
   if possible, overlay the gradient descent trajectory on it.
   This classical visualization connects the surface geometry to
   the optimization path and is a hallmark of thorough ML
   coursework.

The polynomial regression notebook is notably strong — the M1/M2/M3
comparison, the w_MT sweep, and the inference demo are all handled
cleanly and with appropriate physical interpretation.
